# Magnetic Master

3D-игра в браузере, в которой веб-камера заменяет джойстик. Ты управляешь магнитным полем: левая рука наводит прицел, правая хватает и бросает металлические предметы на складе, чтобы победить врагов. Если техника жеста неверна, игра говорит, что именно исправить.

## 5. Игровой цикл и потоки данных

```
Камера ──(requestVideoFrameCallback, ~30 FPS)──▶ HandTracker ──▶ Features ──▶ SharedState
                                                                                  │
requestAnimationFrame (60 FPS) ──▶ GestureManager.update(dt) ◀──────────────────┘
                                        │
                                        ├──▶ ErrorCoach (метрики → подсказки)
                                        └──▶ World.update(dt) (физика, враги, урон) ──▶ рендер
```

- Трекинг и рендер работают независимо. Жесты читают **последнее** значение из `SharedState` и интерполируют между кадрами трекера.
- Если трекер потерял руку на более чем 300 мс: прицел замирает, захваченный объект отпускается мягко (без броска), в HUD подсказка «Рука вне кадра».
- Видео с камеры показывается зеркально в углу (примерно 240×180) с накладным скелетом. Это обязательная обратная связь по кейсу.

**Производительность:** видео 640×480, `devicePixelRatio ≤ 1.5`, тени от одного источника, `InstancedMesh` для одинаковых предметов, переключатель качества в настройках.

## 6. Управление и жесты

### 6.1. Таблица жестов

| # | Жест | Рука | Действие |
|---|---|---|---|
| 1 | Ориентация кисти | Левая | Прицел и поворот камеры |
| 2 | Кулак (при наведении на предмет) | Правая | Захват предмета |
| 3 | Толчок вперёд + раскрытие кисти | Правая | Бросок |
| 4 | Кулак | Левая | Магнитный щит (останавливает и отражает пули, тратит энергию) |
| 5 | Открытая ладонь на камеру, удержание 0.7 с | Правая | Притяжение: предметы в конусе слетаются к игроку |

Требование кейса «минимум 3 жеста» выполнено с запасом.

### 6.2. Какие координаты использовать

Из MediaPipe берём `worldLandmarks` (метры, начало координат в центре кисти) для ориентации и формы руки, и обычные `landmarks` (нормализованные экранные) для положения в кадре и скорости.

Индексы: 0 запястье, 4/8/12/16/20 кончики пальцев, 5 основание указательного, 9 основание среднего, 17 основание мизинца.

### 6.3. Левая рука: прицел

```ts
// вектор «вперёд» по кисти: запястье → основание среднего пальца
const f = normalize(sub(w[9], w[0]));
const yaw   = Math.atan2(f.x, -f.z);
const pitch = Math.asin(clamp(-f.y, -1, 1));   // знаки проверить опытным путём

// нормаль ладони, для roll
const n = normalize(cross(sub(w[5], w[0]), sub(w[17], w[0])));
```

Пайплайн: калибровка → вычитание `yaw0/pitch0` → мёртвая зона → усиление → One Euro → ограничение → aim-assist.

| Параметр | Значение по умолчанию |
|---|---|
| Калибровка | 2–3 с в нейтральной позе, среднее значение |
| Мёртвая зона | 2–3° |
| Усиление | ×2.5 (±25° руки ≈ ±60° камеры) |
| Пределы | yaw ±70°, pitch ±35° |
| One Euro | `minCutoff = 1.0`, `beta = 0.02`, `dCutoff = 1.0` |
| Aim-assist | конус 5°: притяжение прицела к ближайшему врагу, сила 0.15 |

Запасной режим (переключатель в настройках): 2D-позиция центра ладони как курсор. Включать автоматически, если дисперсия yaw при неподвижной руке превышает порог более 3 с.

### 6.4. Правая рука: определение кулака

```ts
const palm = dist(w[0], w[9]);                         // масштаб кисти
const tips = [4, 8, 12, 16, 20];
const closure = avg(tips.map(t => dist(w[t], w[0]) / palm));
// открытая ладонь ≈ 1.8+, кулак ≈ 1.0–1.2
// гистерезис: вход в кулак при closure < 1.15, выход при closure > 1.45
```

Значения подобрать по логам на реальных руках (лог `closure` в консоль в debug-режиме). Дополнительно требовать, чтобы состояние держалось 2 кадра подряд (антидребезг).

### 6.5. Автомат захвата и броска

```
IDLE ──(открытая ладонь + объект под прицелом)──▶ HOVER   (подсветка объекта)
HOVER ──(кулак)──▶ GRAB                                     (объект тянется к точке удержания)
GRAB ──(движение руки)──▶ объект следует, смещение до ±1.5 м
GRAB ──(толчок вперёд + раскрытие)──▶ THROW
THROW ──▶ COOLDOWN (0.4 с) ──▶ IDLE
HOVER ──(потеря объекта из прицела > 0.3 с)──▶ IDLE
```

**Захват:** не телепорт, а пружина.

```ts
const toTarget = sub(holdPoint, body.translation());
const v = clampLength(scale(toTarget, K), MAX_PULL_SPEED); // K ≈ 8, MAX ≈ 25 м/с
body.setLinvel(lerp(body.linvel(), v, 0.25), true);
// + лёгкое вращение и шум для ощущения «магнетизма»
```

Тяжёлые предметы: чем больше масса, тем плотнее должен быть кулак (порог closure ниже) и тем дольше набирается захват (`grabTime = mass / 100` с, но не более 1.2 с).

**Бросок:** условие = переход кулак→ладонь **и** скорость запястья выше порога. Скорость считать по экранной скорости запястья и по росту размера ладони (движение к камере).

```ts
power    = clamp(handSpeed * GAIN, 12, 40);   // м/с
velocity = aimDirection * power;              // летит туда, куда смотрит левая рука
// самонаведение первые 0.5 с к ближайшему врагу в конусе 8°, сила 0.3
```

### 6.6. Щит и притяжение

- **Щит:** левый кулак ≥ 0.2 с. Сфера/купол перед игроком, пули, попавшие в него, отражаются (`velocity = reflect(velocity, normal) * 0.8`). Расход энергии 20/с, восстановление 8/с без щита. При энергии 0 щит выключается.
- **Притяжение:** ладонь на камеру 0.7 с. Все металлические предметы в конусе 20° и радиусе 12 м получают импульс к игроку и зависают на расстоянии 2–3 м. Кулдаун 6 с.

### 6.7. Приоритеты жестов

Одновременно левая и правая рука работают независимо. Внутри одной руки приоритет: щит > прицел (левая), бросок > захват > притяжение (правая). Во время активного щита прицел замораживается.

## 7. Режим «ошибка» (обязательный твист)

Модуль `coach/errorCoach.ts` получает поток метрик от `handFeatures` и событий жестов. Для каждого правила: условие, подсказка, приоритет, кулдаун. Подсказка всегда говорит, **что не так и что изменить**.

| Приоритет | Метрика | Условие | Подсказка | Подсветка |
|---|---|---|---|---|
| 1 | Confidence трекера | < 0.5 дольше 1 с | «Мало света или рука закрыта: включи свет» | рамка видео |
| 2 | Положение в кадре | ладонь в 8% от края | «Правая рука у края кадра: сдвинься к центру» | рука |
| 3 | Размер ладони | ниже/выше границ | «Отойди на шаг назад» / «Подойди ближе» | рамка видео |
| 4 | Roll левой ладони | > 30° | «Держи ладонь ровнее: прицел уходит вправо» | левая ладонь |
| 5 | Дрожание | дисперсия yaw за 0.5 с > порога | «Рука дрожит: опусти локоть, замри перед выстрелом» | левая рука |
| 6 | Closure при захвате | пик > 1.3 при закрытии | «Сожми кулак плотнее: пальцы не касаются ладони» | не закрывшиеся пальцы (красные) |
| 7 | Ранний бросок | кулак < 0.3 с | «Объект не успел стабилизироваться: держи кулак секунду» | правая рука |
| 8 | Скорость броска | < порога | «Слабый бросок: толкни рукой резче вперёд» | запястье |
| 9 | Направление броска | угол к прицелу > 35° | «Бросок ушёл вбок: толкай руку в сторону прицела» | правая рука |

**Правила показа:**
- Одновременно одна подсказка (тост в HUD, 2.5 с), выбирается с наименьшим номером приоритета.
- Кулдаун 3 с на каждый тип, чтобы не спамить.
- Красная подсветка нужной части скелета на оверлее (для «пальцев, которые не закрылись» использовать индексы кончиков с `dist(tip, wrist)/palm > 1.3`).
- Счётчик ошибок каждого типа накапливается и выводится на экране итогов: «Главная ошибка: слабый бросок (7 раз)» плюс совет на тренировку.
- Значения порогов вынести в `coach/thresholds.ts`, чтобы удобно подстраивать.

## 8. Геймплей и физика

**Арена:** один склад, игрок в центре, предметы вокруг, враги выходят из дверей впереди и по бокам.

**Предметы:** 40–80 rigid body (ящики, бочки, балки, двери авто, арматура), массы 5–200 кг, флаг `metal: true`. Одинаковые формы через `InstancedMesh`.

**Урон врагу:**

```ts
const impactEnergy = 0.5 * mass * relativeSpeed ** 2;
if (relativeSpeed > 6) enemy.hp -= impactEnergy * DAMAGE_K;   // падающие мелкие предметы не убивают
```

**Враги:**

| Тип | HP | Поведение | Что нужно |
|---|---|---|---|
| Охрана | 30 | Стреляет одиночными | Любой предмет |
| Штурмовик | 90 | Очередями, броня | Тяжёлый предмет (≥ 60 кг) |
| Снайпер | 40 | Долгий прицел с лазером, сильный выстрел | Быстрый бросок или щит |
| Мини-босс | 400 | Стреляет и уворачивается | Несколько бросков, комбо |

Пули металлические: щит их останавливает и отражает. Смерть врага: импульс и падение (упрощённый ragdoll).

**Волны:** 3 волны по нарастающей плюс мини-босс. Между волнами 5 с паузы и подсказка по самой частой ошибке.

**Здоровье:** HP игрока 100, регенерации нет. Энергия поля (щит, притяжение) 100.

**Очки:** убийство + множитель комбо (окно 3 с) + бонус точности − штраф за полученный урон.

## 9. Экраны и UX

1. **Старт:** название, кнопка «Играть», запрос камеры, требования к свету и расстоянию.
2. **Калибровка:** 3 с в нейтральной позе с прогресс-кольцом. Повтор по клавише `R` и при потере руки > 5 с.
3. **Обучение:** поднять ящик, бросить в мишень, поставить щит. Каждый шаг с иконкой жеста и подсказкой режима «ошибка».
4. **Игра:** HUD (HP, энергия, счёт, комбо, волна), окно камеры со скелетом, тосты подсказок, прицел по центру.
5. **Итоги:** счёт, точность, убийства, длиннейшее комбо, топ ошибок, таблица рекордов, кнопка «Ещё раз».

Дополнительно: пауза при потере обеих рук на 5 с, кнопка Fullscreen, переключатель качества, переключатель режима прицела (гироскоп/курсор).

Визуал: тёмный склад, холодный свет, свечение поля через bloom, линии магнитного поля от правой руки к предмету, искры при ударе. Звук: гул поля, лязг металла, удары, выстрелы.
